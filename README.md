**Demo Prompt**
"Same Prompt, Different Brain" — You give every team the exact same end-user prompt at the start (something like "plan me a weekend trip to Miami" or "help me prep for a job interview"). Every team uses the starter code and questionnaire to architect their own graph, write their own .cursorrules, and build their own agent. At demo time, judges give every agent the same prompt live and compare results side by side. Non-technical judges just pick which output they'd actually use. Technical judges score the graph design. The .cursorrules file is what differentiates otherwise identical starting conditions.
